# 课程交付与演示清单

## 提交内容

| 内容 | 路径 |
|---|---|
| 项目入口与构建配置 | `README.md`、`CMakeLists.txt` |
| 开发约定与忽略规则 | `AGENTS.md`、`.gitignore` |
| 公共接口与源码 | `include/`、`src/` |
| 测试与操作说明 | `tests/` |
| 需求、设计、计划、测试报告及证据 | `docs/` |

手动打包时只选择以上内容。排除 `build*/`、根目录 EXE、`.superpowers/`、IDE 状态、临时文件和下载的客户端。`.gitignore` 只控制 Git 忽略，不会替手动压缩排除文件。原始 `docs/superpowers/` 是课程设计文档，应保留；根目录 `.superpowers/` 是工具工作目录，应排除。

项目上传准备阶段已初始化 Git；后续交付可通过 `git rev-parse HEAD` 记录实际提交号。此前测试发生在首次提交之前，历史报告不补造提交号。交付压缩包时记录名称、日期与 SHA256；项目整理阶段未生成或对外提交压缩包。

## 演示流程

1. 按 [README](../README.md) 选择一种编译器完成 Release 构建与 CTest。
2. 启动对应产物，端口使用 6380；在另一个 PowerShell 窗口操作客户端。
3. 演示 PING、SET、GET、EXISTS、DEL，并说明数据仅存在于内存。
4. 运行持续连接脚本和已安装客户端的兼容性脚本。
5. 展示架构图、Gantt、PERT 和正式测试报告，说明已验证范围及未测事项。
6. 结束演示后停止自己启动的服务。Ctrl+C 的优雅退出语义仍待专项验收。
